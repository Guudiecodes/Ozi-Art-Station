# Arzzet

3D models, HDRIs and textures, with a private owner admin, Paystack and Flutterwave checkout, and a playable hero character.

    npm install
    npm run dev        # http://localhost:3000

Open /login and create the owner account (owner email: jokesonyou146@gmail.com). Only that email can sign in.
Data lives in `data/` on your own computer. On Vercel use Neon and Cloudflare R2: see docs/VERCEL.md.
